# Сайт «Удивительная и неизведанная Арктика» — frontend + backend

Frontend из присланного архива подключён к backend на **Python + Flask + SQLite**.

## Запуск на Windows

1. Установи Python 3.10 или новее.
2. Распакуй архив и открой терминал в этой папке.
3. Создай виртуальное окружение (необязательно, но рекомендуется):

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

4. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запусти сервер:

   ```bash
   python app.py
   ```

6. Открой **http://127.0.0.1:5000**. Не открывай `index.html` двойным щелчком: страницы должны загружаться через Flask.

## Что работает

- `GET /api/health` — проверка backend.
- `GET /api/stats` — число зарегистрированных участников.
- `POST /api/register` — API регистрации (`name`, `email`, `school` в JSON).
- `POST /api/projects` — сохранение заявки; поддерживает JSON или multipart/form-data и файл PDF/DOCX/ZIP до 50 МБ.
- `POST /api/quiz-results` — сохранение результата теста (`score`, `total`, необязательное `participant_name`).
- `POST /api/contact` — сохранение сообщения из формы обратной связи.

Форма подачи проекта и форма обратной связи отправляют данные в backend. Результат викторины также отправляется на сервер. SQLite-файл `arktika.db` создаётся автоматически; загруженные работы сохраняются в `uploads/`.

## Вход и регистрация через VK ID (OAuth 2.1 + PKCE)

Кнопки «Войти через VK ID» и «Зарегистрироваться через VK ID» на странице `/pages/auth.html`
работают в двух режимах:

- **Демо-режим** (по умолчанию) — если ключи не заданы, создаётся тестовый пользователь.
- **Настоящий VK ID** — включается переменными окружения:

| Переменная          | Назначение                                                        |
| ------------------- | ----------------------------------------------------------------- |
| `VK_CLIENT_ID`      | ID приложения из настроек VK ID                                   |
| `VK_REDIRECT_URI`   | Адрес возврата, напр. `https://ваш-домен/api/auth/vk/callback`     |
| `VK_SERVICE_TOKEN`  | Сервисный ключ доступа (для конфиденциальных приложений)           |
| `VK_ID_BASE`        | Базовый адрес VK ID (по умолчанию `https://id.vk.ru`)             |
| `VK_SCOPE`          | Запрашиваемые права (по умолчанию `email`)                        |

Настройка:

1. Создайте приложение на https://id.vk.com и укажите Redirect URL, совпадающий с `VK_REDIRECT_URI`.
2. Запустите сервер с ключами, например:

   ```powershell
   $env:VK_CLIENT_ID="1234567"
   $env:VK_REDIRECT_URI="https://ваш-домен/api/auth/vk/callback"
   $env:VK_SERVICE_TOKEN="сервисный-ключ"
   python app.py
   ```

3. Страница возврата `/api/auth/vk/callback` должна быть без скриптов и встроенного контента —
   в проекте это серверный эндпоинт, который сразу делает редирект, поэтому требование выполнено.

Роль нового пользователя при регистрации через VK ID определяется выбранной карточкой на форме
(Участник / Руководитель / Эксперт); для руководителя и эксперта заявка уходит на модерацию.

## Важно

Это прототип для демонстрации. Перед настоящим запуском для 10 000 пользователей понадобятся PostgreSQL, production-сервер, HTTPS, аутентификация/администрирование, защита от спама, резервное копирование и корректная политика обработки персональных данных. В форме проекта имя пока сохраняется как «Участник», потому что в текущем frontend нет авторизации/поля имени участника.


## Email-рассылки преподавателя/организатора

В административной панели → «Рассылки» можно выбрать всех пользователей, участников, руководителей, экспертов, ожидающих модерации, конкретного ученика по email или участников конкретной номинации. Для номинации укажи точное название, которое записано в заявке.

Чтобы письма реально отправлялись, настрой SMTP-переменные окружения (если они не заданы, письма сохраняются в `outbox/`, а интерфейс явно сообщает, что реальной отправки не было):

```powershell
$env:SMTP_HOST="smtp.example.com"
$env:SMTP_PORT="587"
$env:SMTP_USER="sender@example.com"
$env:SMTP_PASSWORD="пароль-приложения"
$env:SMTP_FROM="sender@example.com"
$env:SMTP_STARTTLS="1"
python app.py
```

Для SMTP через SSL вместо STARTTLS установи `SMTP_SSL=1` и подходящий порт (обычно 465). Не публикуй пароль SMTP в коде или репозитории.

**Сообщения ВКонтакте:** вход через VK ID не даёт сайту права писать пользователю в личные сообщения. Для реальной доставки в VK нужно отдельно подключить сообщество/бота, настроить токен, разрешения и согласие пользователей. Сейчас такой канал не притворяется рабочим: сервер вернёт понятную ошибку, пока интеграция не настроена.
